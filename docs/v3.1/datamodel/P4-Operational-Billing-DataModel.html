1 · Overview

Mode flip
Meter → soft caps
Emit-only mode (P1) flips to soft caps. quota_policy.action_on_soft = warn by default; response carries X-Projex-Quota-Remaining.
Billing first invoices
Catalog v1 ⇒ PDF + Stripe push
Monthly cron reads ClickHouse rollups, applies catalog rates, writes invoice + line items, generates PDF, pushes to Stripe / Razorpay.
Integration framework
Common connector spine
OAuth + schema mapping + bidirectional sync + rate-limit handling + webhook ingestion + cursor state. Every later connector implements this contract.
