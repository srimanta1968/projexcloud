P8 — Deployment Variants

Four deployment topologies for enterprise and regulated buyers. BYOK / CMEK · Sovereign Cloud · On-Prem / Air-Gapped · Active-Active Tier-G+. No new SDKs — these are topology + operational changes that extend the existing schemas with variant-specific tables.
Phase: P8 (parallel from week 22+)
Maps to wave: n/a — variant-specific
Gates closed: — per-variant
PRD: prd/P8-Deployment-Variants.md
Anchor docs: Architecture §22A

1 · Overview

Variant A · BYOK / CMEK
Customer key wraps Tenant Key
Customer CMK sits between Pool KEK and Tenant Key. Revoke renders tenant data undecryptable. Composes sdk-vault + sdk-secrets.
Variant B · Sovereign Cloud
Isolated regions · partner-operated
FedRAMP · IL5 · China PIPL · EU sovereign. SDK estate identical; topology + operator differ.
Variant C · On-Prem / Air-Gapped
Single-cluster K8s · signed quarterly bundles
Local AI Gateway against Llama/Mistral; webhook outbound restricted in-cluster; federation disabled.
Variant D · Active-Active Tier-G+
RPO ≤ 5s · RTO ≤ 60s
Sync replication for audit / payment; async for the rest; monthly chaos drills.
How P8 extends earlier schemas. Rather than introducing a parallel domain, P8 adds variant-specific columns and tables that sit alongside the existing schemas from P1–P7. The matrix below is organized per-variant, with each table noting the schema it extends.

3 · Variant A · BYOK / CMEK

BYOK / CMEK extension to sdk-vault

Variant A · MODIFIED
Customer's CMK becomes the wrapping key for the Tenant Key — sits between Pool KEK and Tenant Key. Revoke ⇒ tenant data undecryptable across all pools.

4 · Variant B · Sovereign Cloud

Sovereign region topology

Variant B
Sovereign region = isolated pool family (own Admin · App · Evidence · Vector · Warehouse · KMS) with no data, telemetry, audit, or control-plane signal leaving the region. SDK estate identical; topology + operator differ.
PRD §: 5.BFRs: FR-SOV-1 … FR-SOV-8Extends: routing + new sovereign schema

6 · Variant D · Active-Active Tier-G+

Active-Active extension to sdk-pool-router

Variant D
Synchronous replication for audit / payment; async for everything else. Per-tenant home-region pin with low-latency read replicas in paired regions. RPO ≤ 5s · RTO ≤ 60s.
PRD §: 5.DFRs: FR-AA-1 … FR-AA-7Extends: routing + new active_active schema
