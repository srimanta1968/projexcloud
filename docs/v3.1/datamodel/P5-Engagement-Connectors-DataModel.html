Encounter (L5) and Relationship (L6) lifecycles; CRM · Content · Service Request · Event · Campaign · Social — all referencing encounter_id. Plus the enterprise connector roster (Salesforce · M365 · GWorkspace · Jira · Linear · Zendesk · HubSpot · Zoom) and HDK editors.

1 · Overview

Domain layer
Encounter + Relationship
Encounter (L5) is the unit-of-work for every vertical (visit, order, deal, session, capital call). Per-encounter Vault key opened on open, shredded on seal.
Lint rule
No parallel work-unit primitives
Verticals must reference encounter_id — no separate visit/order/session tables. Enforced by CI from this phase forward.
Connector roster
8 enterprise connectors
Salesforce · M365 · GWorkspace · Jira · Linear · Zendesk · HubSpot · Zoom. All on the framework from P4; each exposes a tool manifest for the P6A agent CapabilityGraph.
