P1 — Foundation Spine Data Model

Per-SDK entity model, columnar tables, ERDs, events, and pool placement for the foundation spine (Contracts · Vault · Audit · Pool Router · Meter). This is the substrate every later phase routes through.
Phase: P1 (Weeks 1–9)
Maps to waves: W0 (Foundations) + W1 (Compliance + Pool + Meter)
Gates closed: G1 · G2 · G3
PRD: prd/P1-Foundation-Spine.md
Anchor doctrine: Architecture §3A · §3B · §8B

1 · Overview

P1 ships the platform substrate: typed contracts, a 7-tier vault with cryptographic-shred, an append-only audit chain, the pool router resolving (tenant_id, app_id) → dsn, and a universal meter gate in emit-only mode. Everything in this phase is read or written by code in every later phase — so the data model here is load-bearing.

Doctrine #1 · G1
Opinionated Constraints
10 lint-enforced rules. Data model implication: no raw pg.Client outside withTenant; cross-pool joins require @cross_pool_sanctioned.
Doctrine #2 · G2
Polyglot Persistence
Postgres pools = OLTP + PII only. ClickHouse = telemetry rollups. Kafka = events. Redis = cache + quota state. S3 = audit archival + blobs. KMS = key material.
Doctrine #3 · G3
Event Type Registry
Every event type registered with retention class (transient · operational · regulated) and conflict policy. Producers reject unregistered types at runtime.
How to read this document. Each SDK section below contains: purpose · pool placement · entity tables with columns · per-SDK ERD · events emitted/subscribed · pricing surface · cross-references. Tables list logical columns, not full DDL — the source of truth for DDL is the migration files that ship with each SDK package.

6.3 · The seven tiers — what wraps what

TierScopeWrapsShred effect
rootPlatformApp KEKsCatastrophic — platform-wide; never shredded.
appApp family (healthcare, realty, …)Pool KEKs in that appApp-family wipe; not normally used.
poolOne poolTenant keys in that poolPool's data undecryptable; other pools unaffected.
tenantOne tenantPersona, encounter, membership for that tenantTenant offboarding — all that tenant's data undecryptable.
personMaster personApp identities, persona identity facet, tenant memberships, encounters referencing this personGlobal right-to-erasure across all pools/regions.
deviceOne deviceOn-device captures, biometric templatesStolen-device case — only that device's local payloads.
encounterOne encounterEncounter payload, tied evidence blobsSingle-encounter purge / retention expiry.
