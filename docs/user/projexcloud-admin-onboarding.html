ProjexCloud Admin (Platform Owner) — Onboarding Guide

The highest-trust role: register Apps, govern Orgs & resellers, set platform policy, and own platform security.

Part of the onboarding suite. See onboarding-overview for the three-portal model and the identity model. Persona guides: Tenant Admin, Tenant Developer, App User, Platform Admin, ProjexCloud Admin.

Who you are

You own the platform itself. Where Platform Admin operators run day-to-day operations across tenants, the ProjexCloud Admin sets the structures they operate within: the Apps that exist, the Orgs/resellers that govern tenants, platform-wide pricing and policy, sovereign/on-prem footprints, and the security posture. You hold platform super-admin authority and are accountable for break-glass.

Registering an App (the prerequisite for every tenant)

  1. Define the App: name/app_id, data model & event namespace, and the role-template catalogue tenants will draw from.
  2. Set module subscriptions (which SDK capabilities the App offers) and default isolation policy.
  3. Hand off to Platform Admin operators to provision tenants under the App.
  4. For a customer building multiple products, register one App per product under their Org; tenants and members are then isolated per App.

The five-identities discipline

Platform control planes separate five identities on every privileged action: the end subject, the acting operator, the service/agent, the tenant, and the platform itself. Authorization is obligation-bearing (a decision can carry obligations like "log", "notify", "step-up"), the PDP is fail-closed, and break-glass is audited. As ProjexCloud Admin you own these guarantees.

Security ownership — portal authentication

Active risk you own. Tenant Admin and Platform Admin portals currently render without an enforced login gate, while their server actions carry privileged tokens. Mitigate now with network restriction; the durable fix is the Portal authentication middleware (session verification + role-gated access per portal), tracked as a Projexlight feature with scenarios and implementation tasks.
